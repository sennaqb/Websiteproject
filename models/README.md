# Tiffany's model

Export her from VRoid Studio (Export > VRM, VRM 1.0) and save it here as `receptionist.vrm`.
Optional daily outfits: `receptionist-day1.vrm`, `receptionist-day2.vrm`, `receptionist-day3.vrm` (she rotates through them).
Until a file is here the game uses the three-vrm sample model.

In VRoid Studio: Outfit tab for the blouse/skirt (skirt length is a slider), Body > Bust for size, and
Bust "Sway" (spring bones) for physics. If the export has no bust spring bones the game adds a soft sway itself.

Current: receptionist.vrm is Tiffany as made in VRoid Studio (source project in source/Dealership_Receptionist.vroid). Open the .vroid in VRoid Studio to edit her, then re-export.

Outfit rotation: receptionist.vrm on odd days, receptionist-beach.vrm (Beach Day) on even days. Add more looks to RECEP_LOOKS in js/game.js.

Beach Day skin: tiffany-beach-skin.png = her body texture with the 'Golden Summer' bikini (Booth item 4778162 by The Cadenza Store) composited on and the painted underwear removed.

More laundry-day bikinis: tiffany-beach-red/-black/-pink.png = her body texture with a CC BY-SA bikini texture set supplied by the owner (credit the creator if the game is shared publicly). Laundry days cycle through all four by day number.

Head-turner customers: export up to three VRoid women as customer-1.vrm, customer-2.vrm, customer-3.vrm.
They must clearly be adult women (mature face preset, adult proportions). Until a file is here, they use the cartoon stand-in.

Current customers: customer-1.vrm (long dark hair, red fitted dress), customer-2.vrm (blonde, crop top and jeans, sunglasses on her head), customer-3.vrm (curly brown hair, little black dress, gold hoops). All VRM 1.0 with hair and bust spring bones. Customer 3's hoops were placed in the exported file, so re-exporting her from VRoid brings back the old hoop position.
